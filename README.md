# Apni Dukaan — Ecommerce Website

Trending Gadgets & Jewellery ka online store.

## Live Website
Is repository ko GitHub Pages se free mein host kiya ja sakta hai:
1. Repo Settings → Pages
2. Source: `main` branch, `/ (root)` folder
3. Save karein — kuch minute mein `https://<username>.github.io/<repo-name>/` par live ho jaayega

## Features
- Shopping Cart, Wishlist, Quick View, Checkout
- Razorpay payment integration
- WhatsApp click-to-chat
- 49 products with real photos and dynamic categories
